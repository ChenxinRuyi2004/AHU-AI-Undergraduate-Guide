# 安徽大学人工智能学院本科生攻略

**安徽大学（安大 / AHU）人工智能学院新生指南 · AHU AI Undergraduate & Freshman Guide**

这是一份面向安徽大学人工智能学院本科生，尤其是新生的非官方新生攻略与校园生活指南。

本攻略由王硕硕在 2025 年担任 2025 级新生导生期间发起，并联系人工智能学院部分优秀学生共同撰写。内容汇集了不同年级、不同发展方向同学的个人经历与建议，希望帮助后来者更快了解大学生活、学习安排与未来选择。

> [!IMPORTANT]
> 随着学校政策、培养方案及校区安排的变化，新生不一定都会前往磬苑校区，文档中的部分信息也可能已经发生变化。请以安徽大学及人工智能学院最新官方通知为准，本攻略仅供参考。

## 阅读前请注意

- 本攻略是多位同学经验与观点的汇集，不代表安徽大学或人工智能学院的官方立场，也不构成任何明确的行动建议。
- 政策、课程、成绩计算、评奖评优、保研、转专业、校园任务及校区安排等内容具有时效性，请务必通过学校、学院、教务处等官方渠道再次确认。
- 文档中保留的联系方式来自撰写时的个人分享，可能已经变更或失效。我们不保证通过这些方式一定能够联系到相关同学，也不保证对方能够回复。联系时请保持礼貌、说明来意，并尊重个人隐私，请勿骚扰。
- 文档中提到的商家、课程、教师或服务均为个人体验，不构成推荐、背书或商业合作。
